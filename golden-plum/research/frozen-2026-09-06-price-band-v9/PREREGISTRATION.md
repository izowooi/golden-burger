# Golden Plum 가격 구간 실험 v9 — 운영 배포 전

운영자가 상승 지속·되돌림·누적 상승 필터 제거를 요청했다. 현재 유효한 직접 호가
한 번으로 판단하며 과거 3/5회 관측·최초 상향 교차·최소 상승·되돌림 조건은 요구하지 않는다.

초기 비교안은 King A 진입 0.60~0.63, Queen B 0.70~0.73, 공통 TP0.97이다.
익절과 진입을 동시에 다른 값으로 바꾸지 않고 진입 가격 차이를 먼저 비교한다.
축구/MLB/NFL은 별도 profile·runtime DB·종목 태그를 사용한다. SL은 축구/NFL 매수가-0.15,
MLB 매수가-0.12로 분리한다. 이는 최적값이 아니라 검증할 가정이다.
0.60/0.70이 객관적인 참 확률이고 0.97이 심리적 과대평가라는 인과를 주장하지 않는다.

축구 직접 승/무/패 YES·NO 6개 또는 비축구 직접 HOME/AWAY 2개 전체가 유효해야 한다.
전체 중 최고값을 강제하지 않는다. 진입 구간·spread 조건을 만족하는 결과 중 $5 ask VWAP가
가장 낮은 것을 택하고 동률은 token ID 순으로 고정한다. 제출 직전 같은 선택을 다시 검증한다.
경기당 실제 또는 불확실 매수는 한 번만 허용하고 기존 주문/수량/수수료/수동 보유 보호는 유지한다.
과거 보유 거래의 저장된 TP/SL을 새 값으로 덮지 않는다. 원래 DB를 삭제·합치지 않는다.

Silver/Gold는 직접 호가·시각·경기 진행·종목·리그·깊이를 계속 저장한다. 재생 grid는
0.55/0.60/0.65/0.70/0.75/0.80 진입과 0.85/0.90/0.95/0.97 익절, 0.05/0.10/0.15/0.20
손절 폭을 포함한다. observations=1은 가격 구간 정책이며 추세 최소 상승값과 중복 집계하지 않는다.
관측 공백·부분 체결·수수료·미해결 표본을 숨기지 않으며 모든 결과를 경기별로 보고한다.

앞으로의 재평가는 종목별 독립 경기 100개와 arm별 체결·비용 확인된 종결50개를 최소 출발점으로
삼는다. 별도 후속 기간 검증과 비용 포함 결과 없이 사후 최고 수익값을 자동 운영 반영하지 않는다.
같은 경기의 다수 결과/정책을 독립 표본으로 세지 않는다. 충분한 근거가 있으면 사용자의 위임에
따라 새 실험 세대를 제안·기록하되, 보유 거래 조건은 변경하지 않는다.

NFL은 정확한 NFL root/season/team identity의 정규시즌·플레이오프·Super Bowl 개별 전체 경기다.
quarter/half/prop/대회 우승자 futures/NCAA를 제외한다. 축구 시계를 NFL에 대입하지 않는다.
시작은 explicit live, 종료는 authoritative ended/resolution으로 판단한다.

코드와 오프라인 검증은 배포 또는 실제 거래소 성공을 의미하지 않는다. 새 profile에 맞춰
Jenkins의 과거 ENTRY/TREND/TP/SPORT 환경변수를 제거하고, 별도 운영 검증 후 실행해야 한다.
