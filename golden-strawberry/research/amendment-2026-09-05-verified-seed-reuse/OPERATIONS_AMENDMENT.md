# 같은 실행에서 완전히 검증한 불변 seed 재사용

126개 회귀 검사 이후 실제2407에서 seed 검증77초, 미해결 목록153초가 관측됐다.
기존 원본/seed 행 전체 검사에서 이미 읽고 검증한 불변 ID/수량을 즉시 버리고,
다시 외장하드의 조건별 인덱스로 읽는 중복을 제거한다.

- 매 실행의 모든 seed 행·칼럼·개수·해시 검사는 여전히 수행한다.
- 모든 검증이 성공했을 때만 같은 Repository 인스턴스와 같은 DB 경로에 작은 ID/수량
  projection을 메모리로 유지한다. 새 검사 시작 시 이전 projection을 즉시 무효화한다.
- 현재까지의 정확한 RESOLVED condition은 매번 DB에서 새로 읽어 제외한다. 원본의
  terminal-at-handoff와 결합한 모집단·정렬·fixed shares는 기존 SQL 결과와 동일하다.
- 영구 cache 파일/테이블이나 추정 가격을 만들지 않는다. 전체 행 분석 API와 검증 없는
  진단 조회의 기존 SQL 경로는 유지한다. 실제 Bot은 검사 실패 후 수집을 실행하지 않는다.
- 원본/anchor/seed·가상 정책·기간·cadence·deadline은 바꾸지 않는다.
