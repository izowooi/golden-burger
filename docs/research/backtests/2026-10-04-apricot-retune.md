## 2. 재조정: 전체 MLB 이력, 두 반기 분할

### 방법

- 기간 2026-03-01 ~ 2026-10-04(UTC, 거래량 2만 달러 이상 2,367경기).
- 빠른 평가기(scratch 전용 스크립트): 경기마다 `Apricot._signal`·`band_walk_check`·paper broker·순이익 TP 판정을 그대로 호출하고,
  경기당 1회 진입하며 포트폴리오 한도는 적용하지 않는다. **엔진과 대조**: 현재 eco 는 엔진 `polylab backtest` 와 779건·손익이 경기 단위까지
  일치했다. 현재 fruit 은 850 vs 851건이다(1경기 차이, 한도 효과).
- grid 7,128셀: tick {75…125, 5분 간격} × window {2, 4} × prob_min {0.85…0.93} × prob_max {0.97, 0.98, 0.99, 0.999} ×
  TP {0.90, 0.92 … 0.99}.
- 분할: 현재 arm 진입 시각의 중앙값(eco 2026-06-21, fruit 2026-06-25)으로 H1/H2 를 나눈다. autopilot 의 백테스트 근거 경로와 같은 규칙이다.
  통과 기준도 같다: 제안 n ≥ 40, 두 반기 ROI 가 모두 현재 이상, MDD ≤ 현재 × 1.2.
- **다중 비교 주의**: 셀이 7천 개라 최고 셀은 운이 섞인다. 거래당 표준오차는 약 0.6%p 다. 그래서 최고 셀 대신 **이웃 셀(prob_min ±0.01)도 두 arm 모두
  통과하는 공통값**을 골랐다.

엔진 재생(`polylab backtest`, 전체 기간) 결과. retro 의 `split_evidence` + `backtest_gate` 를 그대로 돌렸다.

- 최근 120일(autopilot 기본 lookback)만 봐도 둘 다 통과한다. eco −1.27%→−0.90%, MDD 34.3→31.2. fruit −0.52%→−0.24%, MDD 18.2→12.6.
- 이웃 셀 강건성(빠른 평가기): prob_min 0.88·0.90 과 TP 0.92 조합도 두 arm 모두 게이트를 통과한다. prob_min 0.87 은 fruit 에서 실패한다.
- **TP 0.97–0.99 는 채택하지 않았다.** 이 grid 에서 ROI 가 양수인 셀은 대부분 TP 0.99 이다(예: tick115/pm0.93/pmax0.97/TP0.99 +0.62%).
  하지만 2026-10-02 연구자 결정(조기 익절)과 맞지 않는다. resolution_loss(−100%)가 2배 이상 늘고, synthetic 무한 깊이 bid 가 높은 TP 체결을 과대평가한다.
  TP 0.92 는 0.92 이상에서 진입한 포지션에는 여전히 "첫 순이익 bid 청산"과 같다.
- prob_max 0.98 은 fruit 에선 조금 낫지만 eco H1 은 나빠진다. 처치 변수를 늘리지 않으려고 0.999 로 유지했다. window 4 는 일관된 이득이 없었다.
- **모든 셀이 여전히 0 근처 음수다.** 이 변경은 "덜 나쁜" 개선이지 edge 확인이 아니다. apricot 의 가설(후반 선두 과소평가)은 현재 fee 체제에서
  지지되지 않는다. 포스트시즌 이후 2027 시즌 표본으로 다시 판단한다.

### 적용

- 두 yaml 의 `prob_min` 0.90→0.89 와 `take_profit_price` 0.90→0.92 를 사람이 변경했다. TP 는 2 step(max_step 0.01)이다.
  autopilot 의 백테스트 근거 경로(2×max_step, 위 게이트)가 허용하는 범위 안이다.
- A/B 처치는 tick 90 vs 95 하나로 유지한다. 나머지 파라미터는 두 arm 이 같다.

## 재현

```
# Mac mini, 운영 DB 의 VACUUM INTO 사본에서
POLYLAB_ROOT=<scratch>/root uv run polylab backtest --variant apricot-eco --from 2026-03-01 --to 2026-10-05 \
  --params '{"prob_min":0.89,"take_profit_price":0.92}'
POLYLAB_ROOT=<scratch>/root uv run polylab backtest --variant apricot-fruit --from 2026-03-01 --to 2026-10-05 \
  --params '{"prob_min":0.89,"take_profit_price":0.92}'
```
