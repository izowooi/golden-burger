찾고 있던 3-arm 전략: Golden Quince

맞습니다. 어제 만든 A·B·C 전략은 golden-quince입니다. 방향 신호는 같게 두고 BUY 가격의 maker/taker 성격만 바꿉니다. 세 팔은 서로 다른 계정·Jenkins job·DB를 사용하며, 현재 상태는 “구현 완료, 실행 시작 증거 없음”입니다.

A · Passive

execution_mode=passive

spread 안쪽의 maker BUY. 예상 순위 1위.

job: polybot-quince-passive

B · Nearest control

execution_mode=nearest

가장 가까운 tick. 기존 반올림에 가까운 대조군.

job: polybot-quince-nearest

C · Cross

execution_mode=cross

즉시 체결 방향의 taker BUY. 비용 상한 대조군.

job: polybot-quince-cross

상태를 읽는 법

운영 중 현재 배포/운용 사실이 문서 또는 최근 실행 evidence로 확인됨.
구현 완료 코드·테스트·실행안은 있으나 실제 시작 evidence가 확인되지 않음.
simulation 전용 연구 수집만 허용. live 주문은 금지됨.
보류 재개 가능성을 남기고 의도적으로 멈춘 상태. 현재 해당 전략 없음.
폐쇄 완료 가설/운영 종료가 확인됨. 잔여 wallet·redeem·open order 대사는 별도 사실.
중요: close_only/archive_only는 bot lifecycle mode이지 전략 의사결정 상태와 같지 않음.
상태 근거: 전략 포트폴리오, 회고 인덱스, 각 전략의 local HTML/MD. 실제 운영 변경 시 날짜·job·account·config cohort evidence와 함께 이 페이지도 갱신한다.
