golden-quince — Spread Harvest

"시장을 이기려 하지 않는다. 스프레드를 내는 쪽이 아니라 받는 쪽에 선다." — 방향성 예측을 포기하고 실행 측면(maker/taker) 하나만을 수익원으로 삼는 전략.

유형 실행 비용상태 신규 · A/B 사전 등록처치축 execution_mode기본 주문 $5

핵심 아이디어

가격 = 실현 확률  (실측: 99개 셀 중 BH 통과 0개)
   ⇒ 매수 후 보유의 기대값은 비용 전 0

   ⇒ 양수 EV의 출처는 하나뿐: 거래비용의 부호를 바꾸는 것

BUY  지정가 = floor(midpoint)   # 매수호가에 합류 → maker
SELL 지정가 = ceil(midpoint)    # 매도호가에 합류 → maker
                                # 절대 크로스하지 않는다

왜 이 전략인가 — 다른 모든 것이 기각됐다

2026-07-28~29에 5개 전략(cherry·lime·fig·mango·date)을 실측 검증하고 4개를 폐쇄했다. 가설은 전부 달랐지만 결과는 같았다.

검정한 것결과
확률 예측 edge없음. 99개 셀 중 Benjamini-Hochberg q=0.05 통과 0개. 최대 |z|=2.47인데 필요 p ≤ 0.0005
경로 구조 (평균회귀)실재하나 작다. rho=−0.0901, t=−26.2로 매우 유의하지만 되돌림이 7.9 bps에 불과

실행 측면103 bps 차이 — 유일하게 남은 것

실측 왕복 비용은 실행 경로에 따라 부호가 뒤집힌다 ($5 주문 2,139 왕복):

메커니즘 — 기존 14개 봇은 이 축이 무작위였다

rounded = round(round(price / tick_size) * tick_size, 2)   # 가장 가까운 틱

호가가 0.79/0.80이면 midpoint는 0.795다. 이것이 0.80으로 반올림되면 매도호가를 리프트해서 taker가 되고, 0.79로 내려가면 매수호가에 합류해 maker가 된다. 어느 쪽이 될지는 midpoint 셋째 자리에 달려 있다 — 사실상 무작위다.

golden-date 실거래에서 이 무작위성을 자연실험으로 측정한 결과:

반올림 방향n체결률
UP (매도호가 리프트 = taker)49391.1%
DOWN (매수호가 합류 = maker)48739.4%

quince는 이 축을 execution_mode로 설정에 고정한다.

⚠ 경쟁 가설 — 아직 기각되지 않았다

"패시브가 얻는 1틱 할인은 역선택으로 상쇄된다." 패시브 주문은 가격이 나에게 내려왔을 때 체결되고, 그것은 계속 내려갈 수 있다는 뜻이다.

golden-date에서 진입 밴드를 통제해 종결 ROI를 비교하면 부호가 밴드마다 뒤집힌다(−3.80 / −12.01 / +6.37 / +2.64 pp, n=30~64). 역선택은 현재 DB로 측정 불가능하다 — 거래에 가장 가까운 snapshot이 평균 135분 떨어져 있다.

그래서 이 전략은 "확신"이 아니라 사전 등록된 실험이다.

진입 · 청산 규칙

golden-queen에서 의도적으로 그대로 상속한다. 신호가 아니라 실행이 처치이므로, 신호는 A/B 전 팔에서 동일해야 한다.

#진입 조건 (모두 충족)
1표준 이진 시장 ([Yes, No], price/token 각 2개, negRisk is False 명시)
2YES-only
3직전 persisted YES < 0.90 AND 현재 YES ∈ [0.90, 0.94] — 최초 상향 교차만
4lineage: 현재 snapshot은 이번 sweep의 양의 ID, 직전과 0 < gap ≤ 15분
5시계: 비스포츠·경기 전 (0h, 24h], 경기 중은 kickoff 후 360분까지
6event_id 필수, event당 동시 1개
7주문 직전 fresh midpoint가 밴드 안, best ask ≤ 0.94, spread ≤ 0.02, depth 1.2배, 최소 5.1주
우선순위청산 조건exit_reason
1fresh YES ≥ 0.98 AND 실행가능 bid ≥ 0.98take_profit
2fresh YES ≤ 0.85absolute_stop

trailing stop과 time exit은 없다. 청산 규칙에 edge가 없음이 785건에서 확인됐고(+0.44pp, p=0.74), time_exit의 SELL leg는 TAKER 비중이 59.4%(+16.2 bps)라 패시브 원칙과 정면 충돌한다. 또 max_price를 매수가로 초기화하는 트레일링은 명목 손절을 도달 불가능하게 만든다(cherry·date·grape에서 확인, 실제 발동 중앙값 −14.2% / −16.8%).

golden-date는 판정 기준을 문서에만 적어두고 실측 승률 35.7%(기준 70%)로 계좌 절반을 잃을 때까지 아무것도 멈추지 않았다. quince는 Trader._drawdown_stop_triggered()가 코드에서 차단한다. 청산은 계속되고, 재개는 사람의 판단을 요구한다.

A/B 설계 (사전 등록)

처치는 실행 측면 하나다. 신호·금액·캡·청산은 전 팔에서 동일하다.

팔jobPOLYBOT_EXECUTION_MODE역할
Apolybot-quince-passivepassive처치군 — 절대 크로스 안 함
Bpolybot-quince-nearestnearest대조군 — 기존 14봇과 동일
Cpolybot-quince-crosscross비용 상한 — 항상 크로스

왜 대조군이 둘인가. B만 있으면 "A가 B보다 낫다"를 관측해도 실행 때문인지 우연인지 모른다. C가 있으면 예측된 순서가 생긴다:

순 수익:   A  >  B  >  C
체결률:    A  <  B  <  C

이 부등식이 깨지면 우리의 비용 모형이 틀린 것이고, 그 자체가 정보다. 단일 대조군으로는 얻을 수 없는 falsifiability다.

선택적 4번째 팔 D는 passive + POLYBOT_BUY_AMOUNT=10으로 크기 효과를 분리한다. 자금 여유가 있을 때만 추가하며 A·B·C가 우선이다.

시점조건결정
상시확정손익 ≤ −$40자동 중단
30일A의 CONFIRMED 왕복 < 25건판정 불가 → 진입 조건 완화 후 재시작
30일A 순손익 ≤ 0폐쇄
30일A ≤ B가설 기각 — 실행 측면은 수익원이 아니다
30일A > B > C AND A 순손익 > 0계속, 금액 증액 검토

"승률"은 판정 기준에 넣지 않는다. 승률은 진입 밴드가 결정하며 처치와 무관하다. 재는 것은 같은 신호에 대한 순 실행 비용 차이다.

이 전략이 실패하는 경우

  • 역선택이 스프레드보다 크다. 가장 유력한 실패 모드. → A vs B가 이것을 잰다.
  • 체결이 안 된다. 패시브 체결률 39%대, 0.90~0.95 밴드의 $5 주문 체결률 36.2%. 자금 거절까지 포함하면 신호→포지션 전환율 ~25%.
  • 미체결분이 유령이 된다. 미체결 $5 BUY의 36.4%가 INVALID로 전환되어 max_positions를 잠식한다. 패시브는 미체결이 많으므로 이 위험이 더 크다.
  • 신호가 너무 희소하다. queen은 약 15,500개를 훑어 후보 2건이 나왔다. 진입이 0에 수렴하면 A/B가 성립하지 않는다.
  • dust 잔류. 체결 $5 BUY의 0.3~0.9%가 5주 미만으로 남아 영구 매도 불가.
  • 수수료가 실제로 부과된다. 기록된 fill의 수수료는 전부 0/NULL이지만 Gamma 메타데이터는 94% 시장에 fee_rate 0.04~0.07을 붙이고 있다. 이 불일치는 미해결이다.

알려진 한계

  • 역선택 미측정이 가장 큰 미지수다. market_snapshots에 bid/ask를 함께 적재하므로 30일 뒤에는 직접 측정이 가능해진다.
  • 캘리브레이션 연구는 1주다. favorite 밴드에서 3~8pp의 진짜 edge는 이 표본 크기로는 보이지 않는다(MDE 8~9pp). "edge가 없다"가 아니라 "edge를 보지 못했다"이다.
  • 성과는 order_fills.status='CONFIRMED'로만 확정한다. midpoint 기반 P&L 금지.
  • 패시브는 체결률을 절반 이하로 떨어뜨린다. 부작용이 아니라 설계의 일부이며 표본 축적 속도와의 트레이드오프다.
