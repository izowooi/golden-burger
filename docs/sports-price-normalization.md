# 스포츠 호가 합계 S와 정규화

S는 서로 배타적이고 전체 결과를 덮는 outcome의 같은 기준 호가 합이다.
축구 regular-time 승·무·패에서는 YES 세 개를 사용하고, MLB·NBA·NFL·NHL의
직접 두 팀 moneyline에서는 실제 두 token을 사용한다.

```text
S = p_HOME_YES + p_DRAW_YES + p_AWAY_YES
정규화 가격 w_i = p_i / S
예: 0.99 / 1.03 = 0.961165… ≈ 96.12%
```

이 값은 합이 1인 **정규화한 시장 가격**이다. 실제 승률이나 투자자의 잘못된 판단을
자동으로 증명하지 않는다. 결과가 나온 뒤 별도의 calibration과 비용 후 거래 검증이 필요하다.

## YES와 NO를 구별한다

축구 NO 세 개는 결과가 겹친다. 일관된 확률 벡터라면 YES 세 개의 합은 1,
NO 세 개의 합은 2, 여섯 개를 모두 더한 값은 3이다. 여섯 개를 함께 1로 정규화하지 않는다.
NO의 비교용 정규화 값은 같은 condition의 `1 − w_YES`이며, 실제 NO 호가를 합성하거나
그 값으로 체결했다고 계산하지 않는다. Negative-risk 시장에서는 NO가 다른 결과들의
YES와 연결되는 구조다. [Polymarket의 공식 설명](https://docs.polymarket.com/concepts/negative-risk)

## 어떤 가격을 더했는지 적는다

| 지표 | 정의 | 용도 |
|---|---|---|
| S best ask | 각 결과의 최우선 ask 합 | 매수 쪽 표시 가격 합 |
| S best bid | 각 결과의 최우선 bid 합 | 매도 쪽 표시 가격 합 |
| S mid | 각 결과 `(bid+ask)/2`의 합 | 호가 중간값의 일관성 |
| S ask(q) | 각 결과 **같은 q주**를 사는 full-depth VWAP 합 | 같은 수량의 결과 묶음 매수 비용 |
| S bid(q) | 각 결과 **같은 q주**를 파는 full-depth VWAP 합 | 같은 수량의 결과 묶음 매도 대금 |

현재 공통 깊이 기준은 결과마다 5주다. 각 결과에 각각 `$5`를 쓰면 수량이 달라져
`$5 VWAP 세 개의 합`을 동일 수량 묶음의 비용으로 해석할 수 없다. 단일 전략의 실제
진입 금액 `$5`와 이 공통 수량 기준은 별개다.

거래소 표시 가격은 보통 bid/ask 중간값이며 spread가 크면 마지막 거래 가격을 사용한다.
실제 매수·매도는 각각 ask/bid에서 계산해야 한다.
[공식 가격·호가 설명](https://docs.polymarket.com/concepts/prices-orderbook)

동일 시각의 최우선 호가라면 다음 분해가 성립한다.

```text
S_ask − 1 = (S_mid − 1) + (S_ask − S_bid) / 2
```

따라서 S ask의 상승은 호가 중간값 이탈과 전체 spread 확대의 합이다. 예를 들어
S ask가 1.03이어도 S bid가 1.00이면 매도 쪽에 같은 초과분이 있다고 말할 수 없다.
S를 원인이나 수익성 지표로 해석하기 전에 두 성분을 분리한다.

## 데이터와 실행 경계

- 같은 event·source/cohort·run의 분모만 묶는다. 기본 최대 시각 차이는 2초다.
- 원본 수신 시각이 검증된 자료와 과거 DB snapshot 시각의 근사를 구별한다.
- 미관측·빈 호가·수량 부족·중복·다른 token/condition·crossed book은 0으로 채우지 않는다.
- 거래 가능한 상태와 fee coverage는 별도다. `signal_eligible`는 호가·잔량·OPEN 근거이며
  전체 전략 적격성이나 수익성을 뜻하지 않는다. 실제 비용 근거는
  `fee_evidence_complete`·`cost_evidence_eligible`로 구별한다.
- S 익절도 보유한 token의 실제 수량을 bid 잔량에 팔았을 때의 수수료 후 손익을 확인한다.
  다른 결과의 ask 상승만으로 보유 포지션의 이익을 만들지 않는다.
- 종료 후 정리 호가, 늦은 NO 관측의 미래 정보, 다른 cohort의 정산 정보를 과거 진입·손절에
  소급하지 않는다. 시간 공백과 미확정 결과는 검열 상태로 남긴다.
- 소액 이익 반복과 무손절은 손실 규모도 함께 비교한다. 순익 0.02씩 250회가 원금 5의
  한 번 손실과 같으므로 평균 이익만으로 평가하지 않는다.

공통 계산은 `tools/sports_price_normalization.py`, 전략별 재생은
`tools/sports_s_calibration.py`, 로컬 시각화는 Daily Rsync `/sports`에서 수행한다.
UI는 원본 호가·정규화 가격·S 곡선을 구분하며 실제 A/B 금액 계산에는 원본 호가를 사용한다.
원 DB와 기존 동결된 보고서를 수정하지 않는다.

## 전략 비교에 적용하는 규칙

Watermelon Live·Peach·Plum 각각의 실제 실행 설정을 먼저 고정한다. 같은 경기의
첫 진입 후보에 아래 조건을 적용하며, S 때문에 거절된 후보를 뒤의 유리한 시점으로
바꾸지 않는다. 각 조건의 손익 합계는 해당 조건 안에서만 계산한다. 같은 경기의 여러
조건·수집기를 더해 포트폴리오 수익으로 표시하지 않는다.

| 비교 조건 | 진입 | 청산 |
|---|---|---|
| 기존 설정 | 기록된 전략 신호 | 기록된 TP·SL·정산 조건 |
| 작은 이익·무손절 | 같은 신호 | 다음 전량 매도 순익 ≥ $0.02 |
| S 진입 | 위 조건 + S mid 0.99–1.01 | 위와 같음 |
| S mid 익절 | S 진입 | 순익 ≥ $0.02이면서 S mid ≥ 1.02 |
| S bid 익절 | S 진입 | 순익 ≥ $0.02이면서 같은 5주 S bid ≥ 1.01 |
| 꼬리 손실 비교 | S 진입 | 위 익절 또는 진입가 −0.20의 손절 트리거 |
| ask 기준 진단 | 같은 5주 S ask 0.99–1.02 | S bid 익절 |

Cat/Dog의 사용자 제안인 원래 ask 진입 하한 0.95/0.97, 0.99 익절은 별도 입력 profile로
비교한다. 실제 진입 VWAP가 0.99 이상이거나 0.99 매도에서 비용 후 이익이 불가능하면
진입하지 않는다. 0.99의 이익 매도는 S 조건과 별도로 작동한다. 이는 정규화한 가격의
0.95/0.97을 진입가로 쓰는 규칙이 아니다.

실행기는 고정된 source manifest와 baseline registry를 입력받는다. `run`은 새 출력
디렉터리에 source·계산 코드 SHA, 경기별 경로, 수익 합계, 검열 범위와 비교표를 저장한다.
`--start`, `--end`, `--split`으로 UTC 구간을 명시한다. `--baselines`는 기존 실행 설정과
별도 사용자 profile을 각각 반복 지정할 수 있다. 출력은 표시 호가 연구이며 실거래 설정을
변경하지 않는다. 5분 자료, 기록 시각 근사, BBO만 있는 자료는 가능한 진단 범위를 명시한다.
