# 스포츠 전략 경기별 점검·A/B 재평가 규칙

2026-09-06 사용자 요청: 총액 요약만으로 보고하지 않는다.

## 보고 순서

1. UTC 반열린 구간과 KST 표시, 검증된 DB·로그 기준시각, 누락 범위를 먼저 고정한다.
2. 축구 N경기 → MLB N경기 → NFL N경기 → NBA/NHL 순으로 보고한다. 종목별 경기 수는
   공식 일정/사용자 목록과 시장 모집단 수를 구분하며, 수집되지 않은 경기도 빼지 않는다.
3. 각 종목 안에서 모든 경기를 아래 형식으로 나열한다. 전략별 요약은 그 뒤에 둔다.

| 경기·리그·시작 KST | 전략·Job·팔 | 매수 결과 YES/NO/DIRECT | 체결 시각·VWAP·수량·원금 | 익절/손절/해결 이력 | 확인된 순손익 | 미체결/자료 누락 이유 |
|---|---|---|---|---|---|---|
| 경기별 한 행 이상 | runtime·종목 profile 명시 | 수동 포지션 제외 | CONFIRMED와 fee 근거 | 요청/접수/체결 분리 | 미확정은 미확정 | 정확한 조건·시각 |

수집기 Grey/Gold/Silver/White/Guava는 실제 체결로 표시하지 않는다. 경기별 발견 여부,
직접 6/2호가 완전성, 최초/최종 관측·최대 공백, 종료 추적, 실패/중복 slot, 규모 사다리를
보고한다. 실행 성공과 그 실행에서 실제로 수집했는지를 구분한다.

## 재평가 권한과 기준

사용자는 표본이 쌓인 뒤 A/B 기준을 조정할 권한을 위임했다. 단순히 최근 손익이 나쁘거나
과거 재생 중 최고값이라는 이유로 자동 변경하지 않는다. 종목별 독립 경기100개와
arm별 실제 체결·수수료 확인된 종결50개를 재평가 출발점으로 삼고, 원자료/비용/누락을
확인한 뒤 별도 후속 기간에서도 방향이 유지되는지 검정한다. 같은 경기의 여러 결과·여러
파라미터 조합을 독립 경기로 세지 않는다. 충분한 자료가 없으면 기존값 유지/자료 부족이라고 쓴다.

재평가는 조사·검증 요청 시 수행하며 무인 파라미터 자동 변경 daemon을 설치한 것은 아니다.
수정 시 종목·팔·시행시각·선택 근거·변경 전후 config/source를 기록하고, 보유 거래의
매수 당시 익절·손절을 소급 변경하지 않는다. 하나의 실험에서 비교축을 불필요하게 동시에
바꾸지 않는다. 실제 접근 권한과 서비스 제한을 우회하지 않는다.
